درک عمیق زبان فارسی

یک خط لولهٔ پردازش متن اختصاصی — بسط اعداد و تاریخ‌های شمسی، حروف اضافهٔ ثابت، یکسان‌سازی نویسه‌ها و نیم‌فاصله — پیش از رسیدن متن به مدل عصبی اجرا می‌شود.

🎼

مدل عصبی سرتاسری

Piper VITS روی Sherpa-ONNX — یک مدل واحد که خودش هم آکوستیک و هم صداساز (وکودر) است، برای صدایی پایدار و طبیعی حتی در متن‌های طولانی.

⚡

بهینه‌سازی شده برای موبایل

پخش جریانی جمله‌به‌جمله برای کمترین تأخیر تا اولین صدا، اجرای چندنخی روی CPU و استفاده از شتاب‌دهندهٔ NNAPI روی دستگاه‌هایی که از آن پشتیبانی می‌کنند.
